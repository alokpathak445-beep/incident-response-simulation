5. Strategic Recommendations & Lessons Learned

  • Enforce Multi-Factor Authentication (MFA): Mandate FIDO2/hardware MFA on all internal Remote Desktop (RDP) and interactive workstation logons.
  • Implement Account Lockout Thresholds: Lower lockout threshold to 3 invalid password attempts within 15 minutes to defeat dictionary attacks.
  • Constrain PowerShell Execution Policy: Deploy AppLocker / Constrained Language Mode to block encoded commands and arbitrary download cradles.
  • Enforce Least Privilege & Tiered Administration: Restrict local workstation administrator assignments using Microsoft LAPS (Local Administrator Password Solution).
  • Centralize SIEM Forwarding: Ensure Windows Event Logs are streamed off-host in real-time so that Event 1102 log-clearing attempts do not destroy evidence.
